# learn

Interactive pages for concepts in computer science and software engineering.

**[dinith-heshan.github.io/learn](https://dinith-heshan.github.io/learn/)**

Each page covers one concept and includes something to operate: a parameter to
change, a sequence to step through, a tradeoff that visibly moves. Every page
ends with recall questions, so a concept can be revised in a few minutes rather
than reread from the top.

## How it's organised

```
concepts/<slug>/index.html   one page, self-contained
concepts.json                index of every page
```

Each page is a single HTML file with its CSS and JavaScript inline. No build
step and no dependencies.
